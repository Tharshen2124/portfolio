From July to October 2025 I interned as a Full Stack Engineer at iFAST Global Hub AI. Unlike my first internship, I was given my own project: the **iFAST Global Bank (IGB) Automation Testing System**. It was my first close look at how fintech systems work behind the scenes.

## What I built

The system automatically runs through banking scenarios so engineers don't have to test them by hand.

- **150+ test cases**, including **45 debit card usage scenarios**
- Test scenarios for **Notice** and **Fixed-Term Deposit** products
- **Scheduled CI pipelines** that run the suite and alert engineers on **Slack** when a test fails

A test suite is only useful if people can find and fix a failure quickly. The Slack alerts made sure a broken scenario reached the right people without anyone having to go looking for it.

## Structure and documentation

I also wanted whoever inherits the project to be able to work on it easily.

- I designed and standardised the folder and code structure around **Domain-Driven Design**.
- I wrote the full documentation for the system on **Confluence**, following Confluence best practices.

## What I took away

I used a lot of what I'd learned at MoneyLion here, but I also had to learn new methods, practices and technologies to make it work. Owning a project from start to finish taught me more than any single ticket could. I'm grateful to my colleagues, my supervisor and the other interns for the guidance and good company along the way.
